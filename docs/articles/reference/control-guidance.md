# Contextual control guidance

## Behavior

Current documentation controls receive a compact locally bundled information icon above their target. The icon uses the bundled Material icon-button primitive, a target-specific accessible name, hover/focus tooltip, 44-pixel target and truthful expanded state. It opens an optional nonmodal explanation in the document flow. The direct control remains available. Disclosure summaries remain direct children of their native details element.

## Current coverage

The hand-written guidance inventory lists navigation, tab options, scoped search, regex controls, selection, exports, language, appearance, humour, local wording, settings import, reset, history, dialogs, skip navigation and disclosures. Runtime instances retain the exact target label and their inventory family. Unrecognized controls retain an explicit missing-adapter reason rather than a successful coverage claim.

The search explanation includes a functioning isolated two-article filtering example. Its draft belongs to that opened panel, Reset restores the original query, closing destroys it, and it never changes the real query or history. Other control families currently contain contextual explanations and direct-use instructions only. Their complete action-specific multistep wizard, worked example and interactive playground remain unfinished. The separate `info-icon-guidance` acceptance row remains partial.

## Validation and privacy

The example accepts at most 160 characters and uses synthetic article names only. No live private values seed an example. The explanatory panel never starts an export, destructive action, external connection or settings change. Its controls explain their own local effects without recursively creating another playground.

## Verification

Local negative checks remove each required family or explanation and must fail, then pass after restoration. Synthetic filtering checks verify bounds and independent calls. Browser placement, direct-control preservation, panel open/close, expanded state, sample isolation and long-tab containment require source-bound runtime evidence. Source tests alone do not establish complete guidance acceptance.
