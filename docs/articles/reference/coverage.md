# Documentation implementation inventory

This ledger describes the documentation surface only. It never delegates a required control to the native application. Partial source implementation is not a shipping verdict. The executable completeness check deliberately remains unsuccessful until each required row has implementation, localized copy, focused tests, runtime interaction and capture evidence.

The static website cannot directly own native processes, SSH sessions, operating-system credential storage, or a shared application-data directory. Its equivalents must operate on website content and per-visitor state. Documenting that boundary does not complete those equivalents. The current foundation must not be marketed as full feature coverage.

System fonts are intentionally used, so there are no requested web fonts to vendor. Browser security prevents arbitrary native-editor detection; explicit file export is the current limited handoff. No server API is exposed, so Postman collections do not apply.

All runtime capture, component provenance, touch-device and design-parity fields currently remain unverified. Advanced authentication, toy locks, schedules, narrator, appearance editors, converters, server and model-manager documentation controls require further implementation. No standalone documentation authentication service is claimed.
