# Local tools

Each manager exposes bounded service APIs independently of the graphical interface. Installed capabilities and unavailable operations must be presented separately. A service implementation or successful unit check never proves packaged, sandboxed, installed or live runtime acceptance.

- [File conversion](conversion.md): categorized adapters, signature inspection, durable paged queues and explicitly disabled capabilities without package and isolation proof.
- [Local Ollama](ollama.md): loopback API, streaming requests, local histories, durable pull queues and reviewable installation and launch plans.
- [Minecraft server manager](server-manager.md): source-backed discovery, registry/settings, target plans and transactional local backups.

These services consume external documented APIs. They expose no HTTP server, so an application-owned Postman server collection is not applicable.
