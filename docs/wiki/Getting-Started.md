# Getting started

Use the native application to configure endpoint profiles and select an identity. Explicitly review a new server fingerprint before trust. A changed fingerprint stops authentication. Deployments and their verification have separate outcomes, and cancellation does not imply a server mutation was rolled back.

Keep private identities and credentials out of exported profiles. Read the complete [first-session article](../articles/getting-started/first-session.md) before deployment.
