# Privacy

Private keys, credentials, local wording payloads and source-file metadata do not belong in logs, captures, portable profiles or public records. Documentation preferences remain per visitor in local browser storage. The documentation website does not receive application credentials or connect to SSH endpoints.

Reset website preferences through its settings controls or by clearing this origin's browser storage. Native application storage is separate and is not changed by a website reset.
